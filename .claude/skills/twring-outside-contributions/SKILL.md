# Outside contributions

- Review their pull requests and issues here, and write each reply as a draft for the owner.
- Nothing is posted on GitHub (comment, review, label, close, merge) until the owner approves that reply.
- Outside pull requests are never set to auto-merge.
- Contributions are accepted under the DCO only (ADR-041 in the decisions log): every commit needs a sign-off.
