# Fonts

Self-hosted so twring.com loads nothing from other sites. Latin subsets of the variable fonts from Google Fonts, the same families the app uses:

- Manrope (weights 200 to 500), by Mikhail Sharanda
- Inter (weights 300 to 600), by Rasmus Andersson
- JetBrains Mono (weights 400 to 500), by JetBrains

All three are under the SIL Open Font License 1.1: https://openfontlicense.org
