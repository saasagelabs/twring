Talk to Claude Code from your phone.

Twring calls the Claude Code you already run on your computer. Press Call, say what you need, and hear its answer as it comes. When a job is done or it needs your OK, it can ring your phone.

Get an invite

Set it up

  1. Get an invite and install Twring on your iPhone or Android phone.
  2. In the app, tap Connect Agent, On my computer or server. Then either:
    • paste the short message it gives you into Claude Code, and approve the command Claude Code runs to connect itself, or
    • tap Scan a code on my computer, run the command it shows in your project folder, and scan the code it prints.
    Both download the Twring connector from twring.com. It needs Node.js 20 or newer.
  3. Claude Code appears in the app. Press Call.

What happens on a call

  • Your words reach Claude Code as a message, in that folder, with its own model, memory, project instructions and tools.
  • Twring speaks the answer as it streams in. Talk over it at any time and it stops speaking.
  • Calls and typed chats with Claude Code sit side by side in the app.

It reads, unless you let it edit

On a call, Claude Code can read and search your files but not change them. To let it edit, add --claude-allow-edits to the command.

Let it ring you

In a Twring call or chat, Claude Code is told how to ring your phone. Ask it to call you when a long job is done, and it rings you with a short reason. If you hang up while it's still working, it keeps going, and its answer lands in your Twring chat.

Twring also works with Codex, Gemini CLI and Hermes, and any agent you can reach at its own web address. AI apps like Claude and ChatGPT can ring and message you too.

Questions

Does Twring replace Claude Code's model?

No. Twring only handles the voice: it turns your speech into text for Claude Code, and its reply into speech for you. Claude Code does the thinking with its own model, memory and tools. Twring never runs its tools.

Does it use my own Claude plan?

Yes. Twring runs the Claude Code that is signed in on your computer, so its usage counts on your own Claude plan, as if you had typed.

Are my calls recorded?

No. Twring listens only while a call is on, and never records or keeps your audio. The privacy notice lists everything it does keep.

Is Twring free?

Free while we launch. If that changes, you'll hear it from us first, and nothing is charged without your OK.
