Twring vs Claude Code Remote Control

Remote Control is Anthropic's way to type to the Claude Code session on your computer from the Claude app, and steer it there. Twring is a phone app for talking to Claude Code out loud in a live call, and for letting it ring your phone. If you want to type and approve from your phone, use Remote Control. If you want to talk, or a ring you won't miss, use Twring. Many people will use both.

What Remote Control does well

  • It's official. Made by Anthropic, inside the Claude app, and included with the plans above.
  • The exact session. You drive the same Claude Code session that's open in your terminal, and see its output on your phone.
  • Pushes when you're needed. You can turn on pushes for when a task finishes and for permission prompts and questions, then steer the session from the app.
  • Easy to start. Run claude remote-control, or /remote-control in an open session, and pick it up in the app.

What Twring does differently

  • You talk instead of type. Press Call and speak. Claude Code answers out loud as its reply streams in, and you can talk over it. Good for walking, driving or thinking out loud.
  • A ring, not a banner. Claude Code can ring your phone full screen, even when it's locked, when a job is done or it's waiting on you. Decline with a quick reply if you can't talk.
  • More than Claude Code. The same app calls Codex and Hermes.
  • No call recordings. Twring never records or keeps your audio, and it never runs Claude Code's tools.

Choose Remote Control if

  • You want to type to Claude Code and read its output on your phone.
  • You want to approve the exact prompt waiting in your terminal from your phone.
  • You want something official that comes with your Claude plan, from the app store.

Choose Twring if

  • You'd rather talk to Claude Code than type, with your hands and eyes free.
  • You want a ring you can't miss when it's done or needs you.
  • You run other agents too, and want one place to call them all.

Using both

They don't get in each other's way. A common setup: Twring to talk a task through and get rung, and Remote Control when you want to read a diff or tap Allow on the exact prompt. Set up Twring for Claude Code.

Questions

Is Twring a replacement for Remote Control?

No. Remote Control is the best way to type to the Claude Code session open in your terminal and steer it from your phone. Twring adds a live spoken call and a full-screen ring. Many people will use both.

Does Remote Control have voice?

Its documentation describes no voice feature. Anthropic's help center says that in Claude Code, dictation is available but voice mode isn't. Claude Code's /voice dictation runs on the computer, not the phone.

Can Twring answer Claude Code's permission prompt for me?

No. A Claude Code prompt stays in your terminal, and Twring never approves or runs Claude Code's tools. With Remote Control you can steer the session itself from your phone.

Do both need my computer on?

Yes. Remote Control needs the computer on with the claude process running, and Twring needs the computer on with the Twring connector running.

What do they cost?

Remote Control comes with Claude Pro, Max, Ultra, Team and Enterprise plans, not with an API key. Twring is free while it launches, and Claude Code's usage on a Twring call counts on your own Claude plan.
