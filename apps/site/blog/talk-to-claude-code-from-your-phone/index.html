How to talk to Claude Code from your phone

To talk out loud to Claude Code from your phone, connect it to Twring, a phone app that calls the Claude Code already running on your computer: you press Call, speak, and hear its answer as it streams in. If you only want to type to Claude Code from your phone, Anthropic's own Remote Control in the Claude app does that, and it may be all you need.

What are your options?

There are three different things people mean by "talk to Claude Code", and each has a different answer.

  • Speak instead of typing, at your desk. Claude Code has built-in voice dictation. Run /voice, hold the space bar and talk, and your words appear in the prompt. It needs a Claude.ai account and a microphone on the computer, and it turns speech into text only: Claude's answers stay on screen. (Anthropic's docs, as of November 2026.)
  • Type to it from your phone. Remote Control connects the Claude app on iOS or Android to a Claude Code session on your computer. You start it with claude remote-control or /remote-control, then pick the session in the app's Code tab. Your computer has to stay on, and Claude can send push notifications when a task finishes or needs a decision. (Anthropic's docs, as of November 2026.)
  • Have a spoken conversation from your phone. This is what Twring does: a live call, where you talk and Claude Code talks back, with your hands and eyes free.

If typing on your phone is fine, Remote Control is official, free with your plan, and lets you drive the exact session open in your terminal. Twring is for when you'd rather talk: walking, driving, cooking, or just thinking out loud.

How to set up Twring for Claude Code

  1. Get an invite at twring.com/beta and install Twring. On iPhone it comes through TestFlight, Apple's app for early releases. On Android it's an APK from twring.com, not from Google Play.
  2. Sign in with Google, or Apple on iPhone, using the email your invite went to.
  3. In the app, tap Connect Agent, On my computer or server. Then either paste the short message it gives you into Claude Code and approve the command Claude Code runs to connect itself, or tap Scan a code on my computer, run the command it shows in your project folder, and scan the code it prints.
  4. Both ways download the Twring connector from twring.com. It needs Node.js 20 or newer (Node.js is the free program that runs the small Twring connector).
  5. Claude Code appears in the app. Press Call.

Run the connection in the folder you want Claude Code to work in. Each call starts Claude Code there, as you, with your project's instructions.

What a call is like

You speak. Twring turns your words into text and hands them to Claude Code as a message, like typing it. Claude Code thinks with its own model, memory and tools, on your computer. Twring speaks the answer back as it streams in.

You can talk over it at any time, and it stops speaking. That's called barge-in, and it's what makes a call feel like a call instead of swapping voice notes. Say "stop" and Twring cancels the current turn.

Calls and typed chats with Claude Code sit side by side in the Twring app, so you can switch from talking to typing when you're somewhere quiet.

The usage counts on your own Claude plan, as if you had typed, because Twring runs the Claude Code that is signed in on your computer. Twring doesn't swap in another model.

What can Claude Code do on a call?

By default, it reads. On a call, Claude Code can read and search your files and the web, but not change anything. That's a safe default for a phone call, where you can't see a diff before it lands.

To let it edit files, add --claude-allow-edits to the connect command. Only do that in a folder where you're comfortable with changes you'll review later, ideally one tracked by git.

Twring never runs Claude Code's tools itself. It only carries your words in and Claude Code's answer out.

Speak like it's a call, not a prompt

A few habits make calls work better:

  • Ask for the short version. Long answers with code are hard to listen to. Ask "what's the gist?" and read the details in the chat later.
  • Give it real work. "Find why the login test fails and tell me" works well by voice. Claude Code goes away, reads, and comes back with an answer.
  • Hang up if it's slow. If you hang up while it's still working, it keeps going, and its answer lands in your Twring chat.
  • Teach it names. If Twring keeps mishearing a project or a person, the agent can add them to a word list for later calls.

What you need, honestly

  • An invite. Twring lets people in in waves. It's free while it launches.
  • Your computer on and awake, with the Twring connector running. Claude Code runs on your computer, so if the computer sleeps, the agent shows as offline in the app. The connector can be set up to run in the background and start with the machine.
  • Node.js 20 or newer on that computer, and Claude Code already signed in.
  • An internet connection on both ends. No phone number or phone plan is involved: it's an internet call.

Twring listens only while a call is on, and never records or keeps your audio. The privacy notice lists what it does keep.

What if it doesn't work?

  • Claude Code doesn't answer: check that the computer is awake and the connector is running. If it stays offline, tap Connect another agent, On my computer or server, and link again.
  • It can't hear you: allow the microphone for Twring in your phone's settings, and try the speaker button to switch between phone, speaker and Bluetooth.
  • It says it can't change a file: that's the read-only default. Reconnect with --claude-allow-edits if you want edits.

The support page covers more, and a person reads every email to support@twring.com. Setup in short is also on the Claude Code page.

Questions

Can I talk to the same session I have open in my terminal?

Not directly. Twring starts Claude Code in the folder you connected and keeps one ongoing Twring conversation across your calls and chats. To drive the exact session open in your terminal, use Anthropic's Remote Control.

Does Claude Code's own /voice command work from my phone?

No. Voice dictation in Claude Code needs a microphone on the computer running it, and it turns your speech into text only. Twring is a phone call with spoken answers.

Can I use it while driving?

A Twring call works like any other call on your phone, with Bluetooth if you like. Follow your local rules about phones while driving, and keep Claude Code read-only if you can't check its work.
