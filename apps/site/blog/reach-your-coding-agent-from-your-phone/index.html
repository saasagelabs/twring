Every way to reach your coding agent from your phone, compared

If you want to type to your coding agent from your phone, use the maker's own app: Remote Control in the Claude app for Claude Code, or Codex in the ChatGPT app, both free with plans you may already have. If you want to talk to the agent you already run in a live two-way call, or have it ring your locked phone full screen when it is done, Twring does that with no phone number or telephony account.

Coding agents like Claude Code and Codex now run for a long time on their own. So the question is less "can I code on my phone" and more "how do I keep in touch with the agent while I am away from the desk". There are four different jobs here, and different tools are good at each.

  • Type to your agent from your phone.
  • Dictate: speak, and the words land in the prompt.
  • Talk live: a real two-way voice conversation.
  • Get rung or notified when the agent finishes or needs you.

Everything below about other products is what their own pages said as of November 2026. Products change quickly, so follow the links before you decide.

How do I type to my coding agent from my phone?

Claude Code: the Claude app. Anthropic's Claude Code on mobile page says the Claude app for iOS and Android is a client for Claude Code sessions. From its Code tab you can start cloud sessions, or drive a session running on your own computer with Remote Control (start it with claude remote-control, or /remote-control in an open session). It needs a claude.ai account, not an API key, and your plan has to include it. For Remote Control the computer has to stay on with Claude Code running. When Remote Control is active, Claude can send push notifications when a long task finishes or needs a decision.

Codex: the ChatGPT app. OpenAI's Codex on mobile page says you can start tasks, follow progress, send instructions, approve requested commands and review diffs from the ChatGPT app for iOS. Tasks can run in Codex Cloud or on a connected Mac or Windows PC, which must stay awake and online.

Happy. Happy is an open source (MIT) app that works with Claude Code, Codex and other agents. It has iOS, Android, desktop and web versions and push notifications. It is a good pick if you use more than one agent and want one app that is not tied to a single vendor.

Our honest advice: if typing to Claude Code or Codex is all you want, use the official app. It is made by the people who make the agent, it is in the app stores, and it is probably already included in your plan. Twring does not try to replace it.

Can I dictate to my coding agent?

Yes, at the desk. Claude Code has voice dictation: turn it on with /voice, then hold or tap a key and speak. Your words appear in the prompt. It needs a claude.ai account and a microphone on the machine running Claude Code, and it does not work in cloud or SSH sessions. The answer still comes back as text on screen.

Dictation is the right tool when you are sitting at your computer and would rather speak than type. It is not a phone call, and the agent does not talk back.

Can I talk to my coding agent live?

This is where the choices thin out.

VoiceMode. VoiceMode is an open source (MIT) project for two-way voice conversations with Claude Code and other agents that support MCP (the standard way AI apps add tools). It runs on your computer and uses that computer's microphone and speakers, with cloud speech services through your own OpenAI key or local speech models. Its page does not describe phone access. If you want to talk to Claude Code while sitting at your desk, it is worth a look.

ChatGPT Voice for Codex. OpenAI's voice docs say ChatGPT Voice can start Codex tasks, check progress and change direction in a natural back-and-forth. It's in the ChatGPT desktop app on Plus, Pro, Business, Edu and Enterprise plans, and in Codex on iOS after you pair your phone with a desktop host. If you use Codex on an iPhone with a paid plan, try it first.

Cursor voice. Cursor's changelog announced voice chat with its agents on 6 November 2026, including in Cursor for iOS. It works with Cursor's own agents.

Twring. Twring is a phone app that calls the agent you already run (Claude Code, Codex, Hermes, or an agent server at its own web address) and lets you talk to it live. You speak, it answers out loud, and you can cut in while it is talking. Your agent keeps its own model, memory, tools and permissions. Twring only handles the voice, and it never runs your agent's tools.

To connect an agent on your computer, in the app you tap Connect Agent, then On my computer or server, and follow the steps. The Claude Code and Codex pages show the exact steps for each.

Can my agent ring me or notify me when it is done?

A notification is a banner you might miss. A ring is a full-screen incoming call. Both have a place.

Official push notifications. Remote Control in the Claude app can push a notification when a task finishes or needs a decision. For many people that is enough.

ntfy. A guide on dev.to shows a Claude Code hook sending notifications to a self-hosted ntfy server, reached over Tailscale, with the ntfy app on your phone. It needs Docker and a Tailscale account. Good if you like running your own tools and only want a banner. On its paid ntfy.sh plans, ntfy can also phone a verified number and read a message aloud, one way.

call-me. call-me is an open source (MIT) Claude Code plugin that phones you through Telnyx or Twilio. It needs a carrier account and number, an OpenAI key for speech (or local speech) and ngrok. More on call-me and similar plugins.

agentring. agentring is an open source (Apache-2.0) Android app that your agent can ring over the internet, with no phone number or Twilio. A realtime speech model does the talking and passes the conversation to your agent. It's Android only for now, hosted for free or on your own server.

AgentComms. AgentComms is an open source (MIT) MCP plugin that lets Claude Code and other coding agents place real phone calls to you through Twilio, or message you on chat apps. You need a Twilio account and number, plus speech service keys and ngrok. Its page lists per-minute costs for the calls.

OpenClaw voice-call plugin. If you run OpenClaw, its voice-call plugin places and receives real phone calls through Twilio, Telnyx or Plivo. That needs a carrier account, a number and a publicly reachable web address.

Twring. Your agent can ring your phone, full screen even when it is locked, when a job is done or needs your OK. You answer and you are straight into a live call with that agent. There is no phone number to buy and no telephony account to set up, because the ring goes to the Twring app over the internet, not over the phone network. It works on iPhone and Android.

Which one should I pick?

  • You only want to type to Claude Code or Codex from your phone: use the Claude app or the ChatGPT app. They are the simplest and best supported way to do that.
  • You use several agents and want one open source app to type to them: look at Happy.
  • You want to speak instead of type, at the desk: Claude Code dictation, or VoiceMode for a spoken back-and-forth.
  • You use Codex on an iPhone with a paid ChatGPT plan, or Cursor's agents: try their own voice features first.
  • You already pay for Twilio or another carrier and want calls over the phone network: call-me, AgentComms, or the OpenClaw plugin if you run OpenClaw.
  • You want an app to ring with no phone number, and you're on Android: agentring or Twring. On iPhone: Twring.
  • You want a real conversation with the agent you already run, from anywhere, and a ring you will not miss: that is what Twring is for. See how to get a call when Claude Code is done.

These are not either-or. Plenty of people will use the official app for typing and Twring for talking.

What are Twring's limits today?

We would rather you know before you sign up.

  • It is invite-only. You ask for an invite and we email you the steps.
  • It is not in the app stores yet. On iPhone it installs through TestFlight. On Android it is an APK downloaded from twring.com, not Google Play.
  • Your computer must be on and awake. An agent on your computer can only answer while that computer is on and awake and the Twring tool on it is running. Agents at their own web address do not have this limit.
  • It is voice, not a full mobile coding client. If you want to read diffs on your phone, the official apps do that better.

On the plus side: Twring is free while it launches, it never records or keeps call audio (see privacy), its source is on GitHub, and you can run your own server.

Questions

Is Twring a replacement for the Claude app or the ChatGPT app?

No. Those apps are the best way to type to Claude Code or Codex, read results and review changes on your phone. Twring adds what they do not: a live spoken call with the agent you already run, and a full-screen ring when the agent needs you. Many people will use both.

Do I need a Twilio account or a phone number for Twring?

No. A Twring call and a Twring ring travel over the internet to the Twring app, so there is no phone number to buy and no telephony account to set up. Tools that call you over the phone network, like AgentComms or the OpenClaw voice-call plugin, do need a carrier account and a number.

Which coding agents can I talk to with Twring?

Claude Code, Codex and Hermes on your computer or server, plus agent servers you can reach at their own web address, including OpenClaw and other servers that work like the ChatGPT API. Your agent keeps its own model, memory, tools and permissions.

What happens if my computer goes to sleep?

An agent on your computer can only answer while that computer is on and awake and the Twring tool on it is running. If it sleeps, the call cannot reach the agent. The same is true of Remote Control and the Codex connected computer, which also need the machine on.
