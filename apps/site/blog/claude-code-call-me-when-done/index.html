Make Claude Code ring your phone when it needs you

Claude Code's notification hook can ring your phone like a real call, full screen even on a locked phone, when Claude Code needs permission or is waiting for your input. One command adds it. You can also ask Claude Code to ring you when a long job is done.

Why a ring and not a notification?

Long Claude Code jobs end at awkward times. You walk away, the tests finish, and Claude Code sits there waiting for a yes you didn't know it needed. A notification is easy to miss in a stack of others. A ring is hard to miss, and when you answer, you can talk it through right away.

Twring rings like a phone call: full screen, even on a locked phone. Answer and you're in a voice call with Claude Code, and it tells you why it rang. Don't want to talk? Decline with a quick reply: Busy, Outside, Let's text, or up to 60 characters of your own. Claude Code gets the message.

No phone number or phone plan is needed. The ring and the call go over the internet through the Twring app.

Set it up

  1. Get an invite at twring.com/beta and install Twring on your iPhone (through TestFlight) or Android phone (an APK from twring.com).
  2. In the app, tap Connect Agent, On my computer or server, and follow the steps. Paste the short message into Claude Code and approve the command it runs, or scan the code the command prints. It needs Node.js 20 or newer on the computer.
  3. Turn on notifications for Twring on your phone. Rings can't reach you without them.

That's enough for the first way to get a ring. The Claude Code page has the same steps.

Way one: ask it to ring you

In a Twring call or chat, Claude Code is told how to ring your phone. So just ask: "Run the full test suite and ring me when it's done." It rings with a short reason, for example "The migration finished and all tests pass."

This also works when you hang up mid-task. Claude Code keeps going, and its answer lands in your Twring chat. Depending on your settings you may get a call or a notification, and the first sentence of its reply becomes the ring message.

Way two: let Claude Code ring you by itself

Claude Code has hooks: small commands it runs at certain moments. One of them, the Notification hook, runs each time Claude Code sends a notification. Most of those are because it needs your permission for a tool, or because it finished and has been waiting for your input; a few are for other moments, such as a sign-in finishing. The Twring connector can add a hook there that rings your phone. On the computer, in the folder where you downloaded the connector, run:

node twring-connect.mjs hooks install claude

This adds a Notification hook to your Claude Code settings (~/.claude/settings.json) for all of Claude Code's notifications. From then on, when your Claude Code in the terminal stops to ask for permission or waits for you, your phone rings with Claude Code's own message as the reason, cut to 140 characters. To get a message in your Twring chat instead of a ring, add --message. To remove it, run node twring-connect.mjs hooks uninstall claude. Running install again replaces the old Twring hook instead of adding a second one.

What happens to the permission prompt?

Be clear about this part. The ring tells you Claude Code is waiting. The permission prompt itself is still in your terminal, and Twring doesn't press it for you. Twring never runs Claude Code's tools, and on a Twring call Claude Code works with read-only tools by default (add --claude-allow-edits to let it edit).

So a ring is your cue: answer to hear what it's stuck on and talk it through, or head back to your desk. If you want to tap Allow from your phone, Anthropic's Remote Control is built for that (see below).

Other ways to get pinged

Twring isn't the only option, and some of these may suit you better:

  • Remote Control push notifications. With Remote Control active, Claude can send push notifications to the Claude app when a long task finishes or needs a decision, and you can drive the session from your phone. (Anthropic's docs, as of November 2026.) If you want to approve the exact prompt in your terminal, this is the better pick.
  • ntfy with a hook. A guide on dev.to shows a Claude Code notification hook posting to a self-hosted ntfy server that your phone subscribes to. It's free and fully yours, but it's a notification, not a call, and you set it up yourself.

Twring's difference is the ring itself, plus being able to answer and talk to the agent that rang. Other agents can ring you too: how Codex, Gemini CLI, Hermes and AI apps ring your phone.

Keeping rings useful, not noisy

  • Quiet hours. In Twring's settings, pick hours when no agent can ring you. You can still call them any time.
  • A cap on bursts. An agent can ring you at most 6 times an hour, one ring at a time, and never while you're on a call. A burst of rings is held back on purpose.
  • Messages for small news. Use the --message hook if you only want to read updates later.

When rings don't arrive

  • Check that notifications are on for Twring, and that Do Not Disturb and Twring's quiet hours are off.
  • Check the computer is on and awake, with the Twring connector running. The agent's page in the app shows whether it is online.
  • If you set up the hook in a different folder than the connector, run the install command again from the connector's folder.

Still stuck? See support. Twring never records call audio; the privacy notice lists what it keeps.

Questions

Can I approve Claude Code's permission prompt by answering the ring?

No. The ring tells you Claude Code is waiting, and you can talk to it on the call, but the prompt stays in your terminal. Twring never approves or runs Claude Code's tools.

Does the hook ring me after every reply?

No. The hook rings when Claude Code sends a notification, mostly when it needs permission or has been waiting for your input. To be told when a job is done, ask Claude Code to ring you in a Twring call or chat.

Will rings wake me up at night?

Not if you set quiet hours in Twring's settings. During those hours no agent can ring you, and you can still call your agents yourself.
