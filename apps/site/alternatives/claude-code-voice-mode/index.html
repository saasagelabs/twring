Claude Code voice mode: what exists, and the alternatives

Claude Code has voice dictation (/voice): you speak, and your words land in the prompt. It doesn't have a voice mode that talks back. To have a spoken conversation with Claude Code, use VoiceMode at your computer, or Twring from your phone.

What Anthropic offers

Voice dictation, at your desk. In the Claude Code CLI, voice dictation lets you hold or tap a key and speak, and the words become your prompt. It needs a claude.ai account and a microphone on the computer, and it doesn't work in cloud or SSH sessions. Transcription doesn't use Claude messages or tokens. Claude's answers stay on screen.

Voice mode, in the Claude app only. The Claude app has a voice mode for talking with Claude, but Anthropic's help center says that in Claude Code, "dictation is available but voice mode isn't".

Remote Control, typed. Remote Control lets you type to your Claude Code session from the Claude app. Its docs describe no voice feature.

Alternatives that talk back

VoiceMode, at your computer. VoiceMode is an open source (MIT) project for hands-free voice conversations with Claude Code and other agents that support MCP, the standard way AI apps add tools. It runs on Linux, macOS or Windows (through WSL), with the computer's microphone and speakers. It uses OpenAI's speech services or a compatible one, or local speech models if you want it all on your machine. It isn't a phone app.

Twring, from your phone. Twring is a phone app (iPhone and Android) that calls the Claude Code already running on your computer. You talk, Claude Code answers out loud as its reply streams in, and you can cut in at any time. Claude Code can also ring your phone when a job is done or it needs you. It's free while it launches, by invite.

Which to pick

  • You're at your desk and just don't want to type: /voice. It's built in.
  • You're at your desk and want a spoken back-and-forth, with local models if you like: VoiceMode.
  • You're away from your desk, or want Claude Code to ring you: Twring. Set it up for Claude Code.

Questions

Does Claude Code have a voice mode?

Not a spoken back-and-forth. Anthropic's help center says that in Claude Code, dictation is available but voice mode isn't. The /voice command turns your speech into prompt text, and Claude's answers stay on screen.

Can I use the Claude app's voice mode with Claude Code?

No. Voice mode in the Claude app talks with Claude in the app, not with the Claude Code running on your computer.

Which option talks back?

VoiceMode, on the computer, and Twring, on your phone. Claude Code dictation and Remote Control show answers as text.

Does dictation cost tokens?

Anthropic's docs say transcription for /voice doesn't use Claude messages or tokens. What you then send to Claude Code does, as if you had typed it.
