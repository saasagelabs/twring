# Running Twring on your own server

The operator guide is published at https://twring.com/self-hosting/guide/. Its source of truth is
`apps/site/self-hosting/guide/index.html`; edit it there and deploy the site
(`scripts/deploy-site.sh`).

Related:

- The public page: https://twring.com/self-hosting/ (`apps/site/self-hosting/index.html`).
- The installer and the `twring` command: `deploy/selfhost/install.sh`, `deploy/selfhost/twring`.
- Decisions: ADR-034 in `docs/DECISIONS.md`; security notes: section 24 of
  `docs/SECURITY_AND_PRIVACY.md`.
